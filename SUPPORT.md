# Getting Help & Support (`SUPPORT.md`)

Need help with the **Xernerx Suite**, **Virtue**, or one of our open-source **`@xernerx/*` TypeScript SDKs**? Use the resources below to get fast, accurate support.

---

## 📚 Documentation & Self-Service Resources

Before opening a GitHub issue, please check our official documentation and FAQ:

- **Developer Documentation & API Reference:** [https://docs.xernerx.com](https://docs.xernerx.com)
    - [NPM Packages Catalog (`xernerx` & `@xernerx/*`)](https://docs.xernerx.com/packages)
    - [Official Starter Examples (`Xernerx/examples`)](https://github.com/Xernerx/examples)
    - [REST API v1 Reference](https://docs.xernerx.com/api/v1)
    - [WebSocket Gateway RPC Guide](https://docs.xernerx.com/websocket)
    - [CDN Media Pipeline Guide](https://docs.xernerx.com/cdn)
- **Interactive FAQ:** [https://info.xernerx.com/faq](https://info.xernerx.com/faq)
- **Live System Status:** [https://info.xernerx.com/status](https://info.xernerx.com/status)
- **Release Changelog:** [https://info.xernerx.com/changelog](https://info.xernerx.com/changelog)

---

## 💬 Community & Live Support

For general questions, bot setup help, code troubleshooting, or billing inquiries:

- **Official Discord Support Server:** [https://xernerx.com/discord](https://xernerx.com/discord)
- **Contact Form:** [https://xernerx.com/contact](https://xernerx.com/contact)

---

## 🐛 Where to Report Bugs & Feature Requests

- **Open-Source SDKs & Examples (`xernerx`, `@xernerx/*`, `Xernerx/examples`, `Xernerx/docs`):** Open an issue directly in the respective GitHub repository.
- **Xernerx Web Suite, Desktop Client & Discord Bots (`Virtue`, etc.):**
    - **Bug Reports:** [https://info.xernerx.com/bugs](https://info.xernerx.com/bugs)
    - **Feature Suggestions:** [https://info.xernerx.com/suggestions](https://info.xernerx.com/suggestions)
    - **Public Roadmap:** [https://info.xernerx.com/roadmap](https://info.xernerx.com/roadmap)

---

## 🛡️ Security Vulnerabilities

Please **never** post security vulnerabilities in public issues or Discord channels. Report security findings privately to **[security@xernerx.com](mailto:security@xernerx.com)** in accordance with our [Security Policy](./SECURITY.md) ([xernerx.com/security](https://xernerx.com/security)).
