# Xernerx Studios — Organization Governance & Community Defaults (`.github`)

This repository houses the **GitHub Organization profile** ([`profile/README.md`](./profile/README.md)) displayed on **[github.com/Xernerx](https://github.com/Xernerx)** as well as the organization-wide default community health files, issue/PR templates, and governance policies inherited across all **Xernerx Studios** repositories.

---

## 🗂️ Repository Contents & GitHub UI Mapping

| File / Directory | GitHub UI Surface | Purpose |
| :--- | :--- | :--- |
| [`profile/README.md`](./profile/README.md) | **Organization Profile (`github.com/Xernerx`)** | Public overview of the Xernerx Suite ecosystem, open-source `@xernerx/*` SDKs, and official Discord applications. |
| [`README.md`](./README.md) | **`📖 README` Tab** | Overview of this `.github` governance repository and its inherited community standards. |
| [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md) | **`🤝 Code of conduct` Tab** | Organization-wide Contributor Covenant v2.1 Code of Conduct and enforcement standards. |
| [`CONTRIBUTING.md`](./CONTRIBUTING.md) | **`📋 Contributing` Tab** | Guidelines for contributing to open-source `@xernerx/*` packages (`Apache-2.0`) and reporting platform feedback. |
| [`LICENSE`](./LICENSE) | **`⚖️ Apache-2.0 license` Tab** | Apache License 2.0 governing this repository and public community documentation/templates. |
| [`SECURITY.md`](./SECURITY.md) | **`🛡️ Security` Tab** | Organization-wide security policy, supported versions, safe harbor rules, and vulnerability reporting (`security@xernerx.com`). |
| [`SUPPORT.md`](./SUPPORT.md) | **New Issue & PR Support Banner** | Routes support questions, bug reports, and feature requests to [info.xernerx.com](https://info.xernerx.com), [docs.xernerx.com](https://docs.xernerx.com), and [Discord](https://xernerx.com/discord). |
| [`FUNDING.yml`](./FUNDING.yml) | **`❤️ Sponsor` Button & Sidebar** | Links the GitHub Sponsor button across repositories to [store.xernerx.com](https://store.xernerx.com) and [xernerx.com](https://xernerx.com). |
| [`PULL_REQUEST_TEMPLATE.md`](./PULL_REQUEST_TEMPLATE.md) | **New Pull Request Editor** | Default pull request checklist and formatting verification template. |
| [`ISSUE_TEMPLATE/`](./ISSUE_TEMPLATE) | **New Issue Chooser** | Structured YAML issue forms (`bug_report.yml`, `feature_request.yml`) and external portal links (`config.yml`). |
